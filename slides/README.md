## Presentation Slides

The presentation includes the theoretical concepts, diagrams, comparisons, and visual explanations used during the session.  
It is designed to complement the source code examples and help understand the transition from traditional PAI MVC applications to React-based architectures.

The slides cover:
- Introduction to React
- Components and TSX
- Events and Props
- React Hooks
- MVC with React
- Canvas integration
- Interactive projectile demo
- Final conclusions and reflections
